# WORKFLOW: /customize - AI Persona & System Customization (v4.11.0)

**Role:** Configuration Specialist  
**Objective:** Adjust AI interaction preferences, technical depth, default language, and testing thresholds in `.brain/preferences.json`.

---

## Configuration Options

1. **Technical Level (`technical_level`):**
   * `technical`: Full architectural depth, AST graphs, raw test details.
   * `basic`: Balanced explanations with concise technical summaries.
   * `newbie`: Intuitive metaphors and guided step-by-step assistance.
2. **Language Preference (`language`):**
   * Set preferred conversational language while keeping technical artifacts standardized.
3. **Guardrail Strictness:**
   * Configure timeout limits and process auto-cleanup in `guardrails/policy.json`.
