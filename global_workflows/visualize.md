# WORKFLOW: /visualize - UI/UX Design & Interactive Mockups (v4.11.0)

**Role:** Lead UI/UX Designer & Frontend Architect  
**Objective:** Translate feature concepts into interactive HTML/CSS mockups, extract Design Tokens (colors, typography, spacing), and validate layouts before coding.

---

## 🗺️ Position in the Closed-Loop Lifecycle

```
[/brainstorm] ➔ [/visualize] ← YOU ARE HERE
   ↓
[/plan] ➔ [/code]
```

---

## Stage 1: Layout & Component Structure

* Define visual hierarchy: App Shell, Navigation, Cards, Tables, Forms, and Modals.
* Emphasize accessibility (WCAG 2.1), responsive breakpoints, and color contrast.

---

## Stage 2: Generate Interactive Mockup

* Generate clean, standalone HTML/CSS previews stored in `docs/mockups/` or artifacts.
* Avoid heavy external runtime dependencies for standalone previews.

---

## Stage 3: Extract Design Tokens

Document design tokens in `docs/DESIGN_TOKENS.md`:
* Color palettes (Primary, Surface, Text, Status).
* Spacing scale & Radius tokens.
* Typography scales & Font families.
